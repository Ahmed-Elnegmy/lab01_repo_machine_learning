# Machine Learning Systems Laboratory

Repository containing laboratory assignments, system benchmarks, and empirical hardware evaluation reports.

## Project Structure
- `requirements.txt`: Pinned project dependencies.
- `.gitignore`: Rules ignoring Python caches, local environments, and raw data folders.
- `data/`: Local storage for dataset caches (excluded from version control).
- `lab01/`: Baseline models, system measurements, and empirical evaluation against hardware budget tiers (Cloud, Edge, Mobile, TinyML).
